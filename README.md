
# PingLite

A small website status checker built with Hono, TypeScript and plain JavaScript.

PingLite lets you check whether a website is reachable and see its HTTP status and response time.

Built by hand, not generated by AI.

## Features

- [x] Check website availability
- [x] Display HTTP status code
- [x] Measure response time
- [x] Show connection protocol
- [x] Simple and lightweight interface
